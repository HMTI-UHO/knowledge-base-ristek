# 🐙 GitHub Organization HMTI-UHO

GitHub bukan hanya tempat menyimpan kode, melainkan jantung dari **Digital Ecosystem** kita. Di sini, setiap baris kode yang Anda tulis berkontribusi langsung pada pembangunan infrastruktur himpunan. Halaman ini akan memandu Anda untuk mulai melangkah di dunia *Open Source* HMTI.

---

## 🏛️ Apa itu GitHub Organization HMTI-UHO?
Kami mengumpulkan seluruh proyek teknologi himpunan dalam satu wadah terpusat. Di sini Anda akan menemukan:
- **E-Himpunan**: Source code platform utama kita.
- **Wiki System**: Infrastruktur Quartz yang membangun Knowledge Base ini.
- **Community Projects**: Proyek-proyek kecil hasil dari Bootcamp maupun proyek pengabdian masyarakat.

---

## 🚀 Langkah Awal: Bergabung
Agar Anda bisa mulai berkontribusi dan mendapatkan akses ke repositori internal:
1. **Buat Akun**: Jika belum punya, buatlah akun di [github.com](https://github.com). Gunakan nama asli atau username profesional.
2. **Kirim Username**: Informasikan username GitHub Anda kepada **Tim Developer** melalui kanal `#ristek-dev` di Discord Himpunan.
3. **Terima Undangan**: Periksa email Anda atau kunjungi halaman organisasi untuk menerima undangan bergabung.

---

## 🛠️ Alur Kerja "Open Source Hub" (Workflow)
Untuk menjaga keteraturan kode, kami menggunakan standar industri. Jangan takut salah, karena setiap perubahan akan melalui proses *review*:

1. **Fork/Clone**: Ambil salinan repositori proyek yang ingin Anda pelajari ke akun pribadi Anda.
2. **Create Branch**: Selalu buat *branch* baru untuk setiap perubahan (misal: `fix/tampilan-footer` atau `feat/tambah-materi-ml`).
3. **Commit & Push**: Simpan perubahan Anda dengan pesan commit yang jelas (misal: `fix: memperbaiki link yang rusak di index`).
4. **Pull Request (PR)**: Ajukan PR ke repositori utama organisasi. Tim Developer akan meninjau kode Anda dan memberikan saran jika diperlukan.

---

## 🌟 Sistem "Open Speaker" di GitHub
Sesuai visi kita, jika Anda memiliki keahlian khusus atau proyek pribadi yang bermanfaat bagi himpunan:
- Anda dapat mengajukan diri menjadi **Maintainer** untuk repositori tertentu.
- Anda bisa mendonasikan proyek Anda untuk dikelola bersama di bawah naungan organisasi HMTI agar lebih bermanfaat dan memiliki *legacy* yang panjang.
